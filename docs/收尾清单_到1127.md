## 五、答辩可能被问的问题（提前准备）

1. **PnP 是什么？** —— 已知 3D 点（装甲板四角）和对应 2D 点（图像角点），反求相机位姿。我们固定板的 3D 坐标，求板的 3D 位置。
2. **为什么要手眼标定？** —— 相机装在云台上不是正着装的，要算出相机和云台的相对位置/角度，才能把测距换算到云台系。
3. **四元数为什么比欧拉角好？** —— 无万向节死锁、便于插值、计算稳定；最后转成人能看懂的 roll/pitch/yaw。
4. **为什么这段视频 IMU 姿态几乎不变？** —— 采集时相机固定没动；IMU 在这里的价值是补正"歪装角度"（坐标转换），不是运动补偿。
5. **灯条为什么看起来断开？** —— 拍摄端 LED 高频闪烁 + 卷帘快门造成的伪影，不是代码 bug；轮廓筛选会按真实灯条形状处理。
6. **误检怎么压掉的？** —— 多道常识闸门：灯条高度/填充率、配对高度差/角度差、装甲板宽高比、ROI 位置、距离范围、宽度自洽。
