# 自己调阈值指南 —— 拖滑块 / 看现象 / 抄数值

这份文档教你**自己**找到合适的阈值，不用反复找人改代码。分三块：
① HSV 颜色阈值（哪些像素被当成灯条）、② 灯条筛选（哪些轮廓算灯条）、③ 配对阈值（哪两根灯条配成一块板）。
每一块都告诉你：**在哪个窗口看什么现象 → 调哪个数 → 调到什么程度**。

---

## 开场：先记住一个原则

调参不是凭感觉乱拖，而是"**一次只改一个量，看一个现象**"。
每次只动一个滑块，看画面变化，确认变好还是变差；一次拖好几个，就不知道是哪个起作用了。

另外要分清两类阈值，别混在一起：

| 类别 | 决定什么 | 在哪调 |
|---|---|---|
| HSV 阈值 | 画面里**哪些像素**变白（颜色分割） | hsv 调试器的滑块 |
| 灯条/配对阈值 | 白色区域**怎么变成灯条、怎么配对** | `ArmorDetector.h` 里的 `ArmorParam`，改数字重编译 |

## ① HSV 颜色阈值（最重要，先调这个）

### 怎么打开调试器

在 CLion 里运行配置选 `armor_vision`，Program arguments 填：

```
--mode hsv --frame 900
```

（`--frame` 是**起始**帧号，默认 900。进去以后不用改这个数字重跑，直接按 `d`/`a` 就能前后翻帧，空格键自动播放。也可以 `--image xxx.png` 调单张图，但图片模式没有逐帧功能。）

调试器里的按键：

| 按键 | 作用 |
|---|---|
| 拖滑块 | 实时改阈值 |
| `d` / `n` | 下一帧（换一帧看不同角度的灯条） |
| `a` / `p` | 上一帧 |
| 空格 | 自动播放 / 暂停 |
| `s` | 打印当前阈值并存到 `hsv_values.txt`（抄回代码用） |
| `r` | 恢复默认值 |
| ESC / `q` | 退出 |

画面右上角会显示 `frame 900/1770` 这样的帧号，翻到哪一帧一眼就知道。**建议调完一组值后多翻几帧看看**，别只盯着一帧——阈值要能覆盖整段视频才算调好。

运行后会弹出 **3 个窗口**：

| 窗口 | 看什么 |
|---|---|
| `HSV Tuner` | 滑块 + 掩膜（黑白图，白色=被选中的像素） |
| `Effect: original \| mask \| overlay` | 原图 \| 掩膜 \| 叠加图，左右对照 |
| `HSV channels: H \| S \| V` | 三个颜色通道的伪彩图，用来读出灯条真实的 H/S/V 值 |

### 滑块逐个讲（红色灯条为例）

| 滑块 | 含义 | 怎么判断调对没 |
|---|---|---|
| `color:0Red 1Blue` | 0=调红灯条，1=调蓝灯条 | 先调红 |
| `Red H low1` / `Red H high1` | 红色第 1 段色相范围（靠近 0 那端） | **橙色灯条抓不到，重点调大 high1**。你们视频灯条 H≈12~17，代码默认 high1=30 |
| `Red H low2` / `Red H high2` | 红色第 2 段（靠近 180 那端），处理正红跨 0 的问题 | 一般不动，保持 170~180 |
| `S min` | 饱和度下限，颜色够不够鲜艳 | 调大→少选灰白背景；调小→暗淡灯条也能选上。默认 100 |
| `V min` | 亮度下限 | 调大→暗处不选；调小→暗灯条能选上但噪点变多。默认 80 |
| `morph: 1on 0off` | 形态学开关（1=开+闭运算去噪填孔，和实际检测一致；0=看原始掩膜） | 平时保持 1 |

### 调节目标（看掩膜窗口）

好的掩膜应该是：**灯条位置是干净的白色长条，背景基本全黑**。

- 灯条**没变白** → 调大 `Red H high1`（橙黄灯条），或调小 `S min`/`V min`
- 背景**一大片白**（误检）→ 调大 `S min`/`V min`，或调小 `Red H high1`
- 灯条**断断续续** → 保持 `morph=1`（闭运算会填平），断口是拍摄伪影，见下方 FAQ

### 怎么抄回代码

调到满意后，在调试器窗口按 **`s`** 键，控制台会打印：

```
    int redLowH1  = 0;
    int redHighH1 = 30;
    ...
```

把这几个数抄到 `ArmorDetector.h` → `ArmorParam` 里对应的字段，重新编译即可。

> 好消息：现在调试器的默认值**直接读 `ArmorParam`**，所以你打开就是当前代码正在用的值，调完抄回去一定对得上。（之前这里写死旧值 10，和代码的 30 不一致，已修复。）

快捷键：`s`=打印数值，`r`=恢复默认，`ESC`/`q`=退出。

## ② 灯条筛选阈值（掩膜→灯条）

HSV 调好后，白色区域还要过几道关才算"灯条"。这些在 `ArmorDetector.h` 的 `ArmorParam` 里：

| 参数 | 默认 | 含义 | 现象→怎么调 |
|---|---|---|---|
| `lightAreaMin` | 30 | 轮廓面积下限 | 小噪点被当灯条→调大 |
| `minPoints` | 5 | 轮廓点数下限 | 一般不动 |
| `lightAngleMax` | 40° | 灯条偏离竖直的角度上限 | 斜视角灯条被漏→调大；斜的背景被当灯条→调小 |
| `aspectRatioMax` | 0.5 | 宽/高上限，灯条应细长 | 横向余光被当灯条→调小；粗灯条被漏→调大 |
| `crownMin` | 0.35 | 填充率下限 | 松散的噪声块被当灯条→调大 |
| `lightHeightMin` | 20 px | 灯条像素高度下限 | 远处灯管/反光被当灯条→调大 |

**怎么验证这一层**：看主程序画面上每根灯条的青色椭圆框（`L0/L1...` 编号，默认会画）。
- 真灯条都框上、背景没框 → 这层参数对了
- 余光/背景被框了 → 对照上面表格调 `aspectRatioMax`、`lightHeightMin`
- 真灯条漏了 → 调小 `lightHeightMin`、`lightAreaMin`，或调大 `lightAngleMax`

关掉灯条框：`--no-lights`；想看每根灯条的参数，用 `debug_pipeline` 那个 target 生成的流程图。

## ③ 配对阈值（灯条→装甲板）

两根灯条要"够像"才配成一块板。也在 `ArmorParam`：

| 参数 | 默认 | 含义 | 现象→怎么调 |
|---|---|---|---|
| `pairHeightRatioMax` | 0.7 | 两灯条高度差比例上限 | 斜视角真板漏→调大；错配→调小 |
| `pairYDiffMax` | 90 px | 两灯条中心 y 差上限 | 斜视角漏→调大 |
| `pairAngleDiffMax` | 25° | 倾角差上限 | 真板两灯条一歪一正被漏→调大 |
| `pairDistMaxRatio` | 4 | 间距/灯条高的上限 | 跨整车的乱配→调小；真板漏→调大 |
| `armorAspectMin/Max` | 1.15/3.2 | 装甲板框宽高比范围 | 窄框/细长错框→收紧这两个 |
| `validDistMin/Max` | 0.3/8 m | PnP 距离合理区间 | 离谱距离(0.06m/6m)→本身就是被这个挡掉的 |
| `widthConsistencyMin` | 0.6 | 宽度自洽比值 | 碎片假框→被这个挡掉 |
| `armorCenterYMinRatio` | 0.45 | 装甲板中心最低位置(画面比例) | 背景灯箱误检→调大 |

## FAQ：几个常见现象

**Q：按了 `s`，控制台没看到打印的数值？**
A：三个原因挨个查：
① **焦点不在窗口上**——鼠标先点一下弹出的 `HSV Tuner`（或 `Effect...`）窗口，再按 `s`；
② **数值其实打印了但卡在缓冲里**（CLion 的控制台经常这样）——已修复：现在按 `s` 会强制刷新，并把数值同时写进 `hsv_values.txt`（在 `cmake-build-debug` 目录，画面左下角会显示完整路径）。**直接打开这个 txt 抄数值最省事**；
③ 确认按的是字母 `s`，不是别的键。

**Q：灯条看起来"断成两截"，是不是阈值问题？**
A：不是。这是相机卷帘快门拍 PWM 调光灯条产生的拍摄伪影，像素在拍摄时就丢了，调阈值救不回来。
但**不影响检测**——椭圆拟合法对缺口有容错，能从主体那截拟合出完整灯条。答辩这么说。

**Q：为什么右上角背景灯箱也有 L 编号？**
A：那是颜色分割阶段识别到的灯条（画面上会画出来），但配对阶段会被 `armorCenterYMinRatio` 等挡掉，**不会变成装甲板框**。看到 L 编号但没绿框，说明过滤正常工作。

**Q：调完抄回去，结果和滑块里看到的不一样？**
A：检查两点：① 抄的是 `s` 键打印的值；② 灯条/配对层的参数没改。HSV 只管颜色，后面还有两道筛选，最终框是三层共同决定的。

**Q：想一次看多个帧调参？**
A：现在调试器支持逐帧翻看了——按 `d` 下一帧、`a` 上一帧，空格键自动播放，不用改 `--frame` 重启程序。抄数值时 `s` 打印结果会附带当前帧号，方便你记下"这组值是在第几帧调的"。要快速看整体检测效果，用 `armor_vision --video` 跑完整视频。

---

## 一句话流程

```
--mode hsv 拖滑块 → 看掩膜：灯条白、背景黑 → 按 s 抄回 ArmorParam
→ 重编译 → 跑 armor_vision 看灯条框 → 不对再调 ArmorParam 的灯条/配对阈值
→ 一次只改一个量
```
